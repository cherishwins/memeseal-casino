▲ Section 04 — How To Use This Kit For operators · designers · partners

The kit is opinionated. Use it that way.

Every asset is built to be used as-is. Edit the body copy, swap the data, replace the names. Don't substitute typefaces, don't recolor the italic, don't soften the discipline. The brand survives because the discipline is preserved.

A ·
For Operators
Open the Brand Bible first to internalize the voice. Then use the templates as drop-in production files for letterhead, decks, social posts, and signatures.
↳ START
B ·
For Designers
Extract SVG source from the Logo Pack via Inspect Element. Color tokens and typography stack documented in §06 and §07 of the Brand Bible.
↳ ASSETS
C ·
For Partners & Press
The OG templates and Quarterly Letter are the public-facing surfaces. Use the Pitch Cover for investor materials. All approved fields documented.
↳ EXTERNAL
D ·
For Engineers
The Dashboard mockup in the Brand Bible §09 is the production grammar for The Desk's UI. Bloomberg-terminal layout. JetBrains Mono data. Bullion + Ember alerts.
